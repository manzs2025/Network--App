تطبيق «مبادئ شبكات الحاسب» — خطوات النشر على GitHub Pages
================================================================

أولًا: رفع الملفات (مرة واحدة)
1) ادخل github.com وأنشئ حسابًا إن لم يكن لديك.
2) اضغط زر + أعلى الصفحة ← New repository.
3) اكتب اسمًا إنجليزيًا قصيرًا مثل: networks  — واجعله Public — ثم Create repository.
4) في صفحة المستودع اضغط: uploading an existing file
5) فك ضغط الملف، وافتح المجلد networks-app، ثم حدّد كل ما بداخله (الملفات والمجلدات assets و icons)
   واسحبها إلى صفحة الرفع. (ارفع محتويات المجلد، لا المجلد نفسه)
6) انتظر حتى يكتمل الرفع ثم اضغط Commit changes.

ثانيًا: تفعيل الموقع
7) من المستودع: Settings ← Pages
8) في Source اختر: Deploy from a branch ، وفي Branch اختر: main و /(root) ثم Save.
9) بعد دقيقة أو دقيقتين يظهر الرابط بالشكل:
   https://اسم-حسابك.github.io/networks/
   افتح الرابط وجرّبه، ثم شاركه مع المتدربين.

ثالثًا: التثبيت على الجوال
- أندرويد (Chrome): يظهر زر «تثبيت» في الصفحة الرئيسية للتطبيق، أو من القائمة ⋮ ← «تثبيت التطبيق».
- آيفون (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- الكمبيوتر (Chrome / Edge): أيقونة التثبيت في شريط العنوان.
بعد أول فتح يعمل التطبيق دون إنترنت.

رابعًا: التحديث لاحقًا
- عندما أرسل لك نسخة جديدة: ارفع الملفات نفسها بالطريقة ذاتها (Add file ← Upload files) واضغط Commit changes.
- يصل التحديث للمتدربين تلقائيًا، وتظهر لهم رسالة «تم تحديث التطبيق» فيعيدون فتحه.

ملاحظات
- التطبيق عام ولا يحتاج تسجيل دخول، ولا يجمع أي بيانات؛ تقدّم كل متدرب يُحفظ على جهازه فقط.
- زر «تعديل» غير موجود في نسخة التطبيق؛ التعديل يكون في ملفات HTML الأصلية لديك.
